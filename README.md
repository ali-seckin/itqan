# Itqān

Die Murāǧaʿa des ganzen Qurʾāns in 734 inhaltlich gegliederten Abschnitten. Offlinefähige Web-App ohne Server: Der Fortschritt bleibt auf dem Gerät und lässt sich als Profildatei sichern.

Muṣḥaf: Madanī-Druck 1405 (King Fahd Complex), Seitenschriften QCF V1 des KFGQPC, Layout- und Textdaten über QUL (Tarteel).
