# Itqān

Die Murāǧaʿa des Qurʾān in 739 inhaltlich gegliederten Abschnitten (wahlweise kürzere Anfänger-Abschnitte oder ganze Seiten). Offlinefähige Web-App in sieben Sprachen: Der Fortschritt bleibt auf dem Gerät und lässt sich als Profildatei sichern. Auf Wunsch gleicht ein freiwilliges Konto (Anmeldung per E-Mail-Code, Server in Frankfurt) mehrere Geräte ab. Itqān ist kostenlos, ohne Werbung und nicht kommerziell.

## Quellen

Muṣḥaf: Madanī-Druck 1405 (King Fahd Complex), Seitenschriften QCF V1 des KFGQPC, Layout- und Textdaten über QUL (Tarteel).
